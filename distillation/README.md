
# Act 2 — Distillation

This section focuses on Knowledge Distillation, a technique used to transfer knowledge from a larger, more complex 'teacher' model to a smaller, more efficient 'student' model. This often results in significant gains in inference speed and reduced resource requirements, with minimal or acceptable drops in performance.

## Key Concepts
*   **Teacher Model**: The larger, fine-tuned model (from Act 1) that has strong performance.
*   **Student Model**: A smaller, simpler model designed to learn from the teacher.
*   **Soft-Labels / KD Loss**: The student model is trained not only on hard labels but also on the probability distributions (soft labels) generated by the teacher, often using KL-divergence as part of the loss function.

## Setup and Execution
1.  **Navigate to the `distillation` directory**:
    ```bash
    cd distillation
    ```
2.  **Run Distillation**: Execute the `distill.py` script. This script will load the fine-tuned teacher model, a smaller base student model, and train the student model to imitate the teacher.
    ```bash
    python distill.py
    ```
    *   **Output**: The distilled student model is saved to `./outputs/student-model`.
3.  **Evaluate Student vs. Teacher**: Run `evaluate_student.py` to compare the performance metrics (e.g., ROUGE-L, latency) of the distilled student model against the teacher model.
    ```bash
    python evaluate_student.py
    ```
    *   **Output**: A detailed comparison, including parameter reduction, ROUGE-L scores, and speedup, is saved to `./outputs/student_vs_teacher.json`.

## Outputs and Artifacts
*   `outputs/student-model/`: The saved, distilled student model, ready for deployment.
*   `outputs/student_vs_teacher.json`: JSON file summarizing the comparison between the student and teacher models, highlighting efficiency gains and quality trade-offs (if any).

This phase produces a deployment-ready model that is optimized for inference.
