
# LLM Fine-Tuning, Distillation, and LLM Ops Project

This project demonstrates a complete workflow for fine-tuning a Large Language Model (LLM), distilling it into a smaller, more efficient student model, and then setting up an LLM Operations (LLM Ops) pipeline for serving and evaluating the model.

## Project Overview
This repository covers three main acts:
1.  **Fine-Tuning**: Adapting a base LLM (Llama-3.2-1B-Instruct-bnb-4bit) using LoRA (Low-Rank Adaptation) for a specific task.
2.  **Distillation**: Training a smaller student model to mimic the behavior of the fine-tuned teacher model, focusing on efficiency and speed.
3.  **LLM Ops**: Setting up a local serving endpoint using FastAPI and implementing an automated evaluation gate to ensure quality and prevent regressions.

## Local Setup Instructions
To run this project locally, follow these steps:

1.  **Clone the Repository (after downloading and unzipping)**:
    ```bash
    git clone <your-repo-url>
    cd fine_tuning_distillation_llmops-main # Or whatever your folder name is
    ```

2.  **Create a Virtual Environment (Recommended)**:
    ```bash
    python -m venv venv
    source venv/bin/activate
    ```

3.  **Install Root Dependencies**:
    ```bash
    pip install -r requirements.txt
    ```

## Project Structure
*   `fine_tuning/`: Contains scripts and outputs for the fine-tuning phase.
*   `distillation/`: Contains scripts and outputs for the model distillation phase.
*   `llmops/`: Contains scripts and outputs for the LLM Operations phase (serving and evaluation).
*   `data/`: Sample dataset for training and evaluation.

Refer to the `README.md` files in each sub-directory for detailed instructions on running each specific act.

## Project Artifacts
Upon successful execution of all acts, the following key artifacts are generated:
*   **Fine-Tuned LoRA Adapter**: Saved in `fine_tuning/outputs/lora-adapter`.
*   **Base vs. Fine-Tuned Comparison**: `fine_tuning/outputs/before_after_comparison.json`.
*   **Distilled Student Model**: Saved in `distillation/outputs/student-model`.
*   **Student vs. Teacher Comparison**: `distillation/outputs/student_vs_teacher.json`.
*   **LLM Ops Evaluation Results**: `llmops/outputs/eval_results.json` (generated by `eval.py`).

## Deliberately Excluded Features
To keep this demo concise, the following advanced LLM Ops features were intentionally omitted:
*   Semantic caching or cost optimization.
*   Llama Guard-style moderation or human-in-the-loop approval gates.
*   LangSmith/Arize-style tracing.

These can be considered as potential extensions to the project.
